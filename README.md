# 一方小世界

楚门式人生模拟：一个小世界，一个主人公，从婴儿开始，过完没有剧本的一生。

## 怎么玩

直接用浏览器打开 `index.html` 就能玩，不需要安装、不需要联网、没有后端。
也可以用任何静态服务器打开，比如：

```bash
python3 -m http.server
```

## 这个世界是什么

- **没有剧本**：所有事件由性格、关系、心情、情境现场生成，没有预排的时间线，没有“跳到下一个大事”。
- **世代传承**：主人公会结婚生子，去世后视角传给孩子，家族树一直往下长，模拟永不停。
- **一个像地球一样的世界**：12 个国家、80 亿人口，大城市有机场、地铁、公交，小城镇安安静静；城市会生长、变老，店铺会倒闭，房子会拆迁。
- **人是活的**：邻居、同学、老师、同事，每个人都有名字、性格、自己的生活；借作业可能借、可能拒绝、可能告老师，全看当时的情况。
- **出身随机**：可能生在富裕家庭、普通家庭，也可能生在很穷的、很悲惨的家庭，只决定起点，不决定终点。

## 时间

现实 5 分钟 = 游戏里 1 小时，现实 2 小时 = 游戏里 1 天。
速度可以调（暂停 / 正常 / 快进 / 极速），大事发生时会自动停下来。

## 一条铁律

主人公永远不知道自己是被创造出来的，也不知道有人在看他。他的世界里没有上帝、没有观众。

## 技术

单个自包含的 HTML 文件，无外部资源、无 CDN、无后端，所有数据只存在浏览器本地。
